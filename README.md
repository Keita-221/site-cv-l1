# 🌐 Site CV statique (projet de L1)

Premier projet web, réalisé en première année de **Licence Informatique et Sciences de l'Ingénieur** à l'Université de Bretagne Occidentale (UBO).

**👉 [Voir le site en ligne](https://keita-221.github.io/site-cv-l1/)**

## 📄 Contenu

Site statique de plusieurs pages, sans serveur ni base de données :

| Page | Contenu |
|---|---|
| `index.html` | Présentation |
| `page/formation.html` | Parcours et formation |
| `page/experience.html` | Expériences |
| `page/divers.html` | Divers (vidéo intégrée, centres d'intérêt) |
| `page/Technicien.html` | Page d'un atelier de réparation de téléphones fictif, avec un **calculateur de prix** en JavaScript |

## 🛠️ Technologies

- **HTML5** : structure des pages, formulaires
- **CSS3** : mise en page, police personnalisée, fond répété
- **JavaScript** : calculateur de prix de réparation et interactions (`script/calculateur.js`)

## 💻 Lancer le projet en local

Aucun serveur ni installation n'est nécessaire :

```bash
git clone https://github.com/Keita-221/site-cv-l1.git
```

Puis ouvre simplement le fichier `index.html` dans ton navigateur (double-clic).
